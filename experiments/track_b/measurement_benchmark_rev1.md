## Proposed common evaluation
Freeze D31/D32 join keys and audit metadata, source percentiles and antenna calibration, area-specific R5/T7 exclusions, all exclusion counts and sensitivity. Never substitute snapshot for time median without calibrated environmental state or explicit proxy label. Compare same information tier, state period and physical antenna heights; document ITM clamp as limitation. Prediction input table excludes measured losses. Separate evaluation joins exact identifiers, checks duplicate/missing/extras, finite values and statuses. Retain unsupported denominator; report paired metrics common support plus coverage by area/frequency/height. Censored lower bound b: report max(0,b-pred) separately, no imputed RMSE. Group by physical path and crossed endpoints; three areas insufficient for broad generalization; prospective independent campaigns required. No tuning on evaluation set. New solver required fields model revision, input hash, scenario ID, estimand, status, loss_db (null unsupported), uncertainty and runtime. No new candidate result yet.
