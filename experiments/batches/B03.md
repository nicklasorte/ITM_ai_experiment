## Change

`cfg.diffraction_region = "transhorizon_phased"`: on transhorizon paths
only, the profile-based value is phased in linearly with distance, from
ITM's own diffraction-line value at d_sML (where ITM's line-of-sight fit
joins, so the loss is continuous) to the full profile-based value at d_3
(where ITM itself evaluates diffraction). Line-of-sight-region paths are
untouched, which B02's extension broke. No new constant: both anchors are
ITM's own distances.
