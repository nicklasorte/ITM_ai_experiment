# Batch B05: which mechanism keeps R2's no-signal paths dead?

Planner: Claude Fable 5.2, 2026-11-21. Worker: the session model.
Predictions were committed before any scored run of these settings.

## Purpose

Fourteen structural runs, none kept. The delta construction (401) fits the
measured rows best but predicts signal on 71 % of R2's no-signal rows. D03
showed those rows are multi-ridge paths, and the B04 reviewers listed
controls that were never run. This batch tests mechanisms. **Four of the six
settings fail the physics battery in the planner's code check, so they
can't be kept whatever they score.** They're scheduled because the question
they answer (does counting separated ridges, or restoring ITM's clutter
term, remove the optimism?) decides what B06 builds properly.

Starting evidence (existing runs, from
`experiments/D03-r2-dead-paths/violations_by_edges_rev1.py`):

| R2 rows by Deygout edges | Stock ITM: dead rows violated / measured mean error | 401: dead rows violated / measured mean error |
| --- | --- | --- |
| 0–1 | 32 % / −2.9 dB | 100 % / −15.6 dB |
| 2 | 11 % / +10.8 dB | 49 % / −12.9 dB |
| 3 | 4 % / +31.5 dB | 63 % / −3.0 dB |
| 4+ | 5 % / +16.3 dB | 81 % / −9.9 dB |

Two things follow. 401 predicts too little loss on R2's measured rows at
every edge count, including single-edge paths (−15.6 dB), so a missing
term common to all R2 paths matters as much as edge counting. And on 4+
edge paths 401 is 10 dB low on the measured rows too, so extra multi-ridge
loss there should help both the measured and the dead rows.

## New code

`itm_variant/multi_edge_diffraction_rev1.m`: method `"string_ep"`.
`itm_variant/itm_p2p_core_exp.m`: `delta_bullington_reference` takes any
obstruction method (the same method on the actual and the zero-height
profile, form L_a + max(A_s − L_s, 0), ITU-R P.452-18 eq. (38)–(40)), and
the `"delta_bullington_afo"` control. Tests: 21 of 21 pass. Parity at
defaults: 6.8 × 10⁻¹³ dB. No new free parameters.

- `"string_ep"` (the planner's own proposal): obstructions from the
  stretched string of ITU-R P.526-16 section 4.4, eq. (44). String points on
  consecutive samples are one obstruction (the Recommendation's rule for
  spacings of 250 m or less), which removes the split-top sampling artifact
  B02 found. Neighboring obstructions merge unless the valley between them
  opens to 0.6 of the first Fresnel zone radius somewhere (a reading of
  section 2.5; a design choice). Each obstruction is one knife edge at its
  vertex; losses add as in Epstein-Peterson (NTIA TR-26-580 section 3.3.2).
  The cylinder, sub-path, and C_N terms of section 4.4 are left out because
  the text extraction of their equations was unreliable. On a smooth Earth
  it reduces to the Bullington-point knife edge (tested).
- Proposed but not built: the rounded-obstacle term T(m, n) of P.526-16
  section 4.2. Its loss grows with frequency, which fits D03 (on a given
  path the dead rows are the higher frequencies). The extraction of eq.
  (34)–(36) disagreed with itself on the exponents, so nothing was coded.
  It needs a read of the PDF.

| `delta_p526_cascaded` | fail: 18.5/8.0 (ridge), 38.7/33.0 (rough) |
| `delta_deygout` | fail: 11.9/1.9 (flat), 18.5/8.0 (ridge), 38.3/33.0 (rough) |
| `bullington` with `blocked_paths` | fail: 34.3/33.0 (rough) |

Why the multi-edge settings fail: each counted edge adds at least 6 dB (the
knife-edge loss at grazing), so the loss steps whenever an edge enters or
leaves the count as distance or frequency changes. A keepable version needs
an edge contribution that grows from zero; that is B06's problem if this
batch confirms the mechanism.

## Experiments, ranked by expected value

Reference: stock ITM composite 16.0, screened 13.4, censored 28.0 %; 401
composite 11.5, screened 10.2, Phase 2 cell 14.2, long-term level 15.0,
R2 RMS 19.5 (mean −11.3), VA 15.2, censored 67.6 % (R2 71 %).

### 501-delta-string-ep
- Change: `cfg.diffraction = "delta_string_ep";`
- Source: ITU-R P.526-16 section 4.4 eq. (44) and section 2.5; Epstein and
  Peterson 1953 (NTIA TR-26-580 section 3.3.2); P.452-18 eq. (38)–(40).
- Rationale: separated ridges each cost a diffraction loss; one equivalent
  edge can't represent several.
- Predicted: R2 dead rows violated: 4+ edges from 81 % to 30–60 %, 3 edges
  from 63 % to 30–55 %, 0–1 edges unchanged (100 %). R2 measured mean error
  from −11.3 to between −7 and −2 dB; on 3-edge measured rows it moves from
  −3 to positive (worse). Censored overall 45–60 % (VA stays near 83 %).
  Long-term level 15–19. Composite 11.5–13.5. Battery: fail as listed.
- Confidence: low. This is the main mechanism test.

### 502-delta-bullington-afo (control)
- Change: `cfg.diffraction = "delta_bullington_afo";`
- Source: ITM v1.4 DiffractionLoss clutter term A_fo; B04 reviewer pass.
- Rationale: the smooth-path ITM call drops A_fo, a loss of up to 15 dB that
  stock ITM applies to every diffraction path.
- Predicted: 3–10 dB more loss on most R2 rows. R2 measured mean error from
  −11.3 to between −8 and −3 dB; 0–1 edge dead rows violated from 100 % to
  70–95 %; censored overall 55–65 %. Composite 11.0–12.0 (could improve on
  401). Battery: pass. If censored falls below 50 %, A_fo is a main cause:
  tell the planner.
- Confidence: medium.

### 503-delta-p526-cascaded
- Change: `cfg.diffraction = "delta_p526_cascaded";`
- Source: ITU-R P.526-11 section 4.4.2, eq. (49)–(52).
- Rationale: Deygout's three edges with the ITU-R correction, the method
  ITU-R used before delta-Bullington.
- Predicted: more loss than 501 on long paths. Censored 35–55 %; R2
  measured mean error −5 to +3 dB; long-term level 17–24 (worse than 401);
  composite 12.5–15. Battery: fail as listed.
- Confidence: low.

### 504-delta-deygout
- Change: `cfg.diffraction = "delta_deygout";`
- Source: Deygout 1966; NTIA TR-26-580 section 3.3.3.
- Rationale: 503 without the empirical correction, to separate the edge
  count from the correction.
- Predicted: between 501 and 503. Censored 40–60 %; composite 12–14. On
  30 m profiles Deygout may count the shoulders of one rounded top as extra
  edges (the artifact `"string_ep"` groups away); if 504 has clearly fewer
  violations than 501 on 0–1 and 2-edge rows, that artifact is the reason.
  Battery: fail as listed.
- Confidence: low.

### 505-delta-ep-isolated
- Change: `cfg.diffraction = "delta_ep_isolated";`
- Source: Epstein and Peterson 1953; P.526-16 section 2.5.
- Rationale: the two-horizon-edge method that passes the battery; its strict
  isolation test merges most pairs, so it mostly tests the delta
  construction without Bullington's eq. (57) correction.
- Predicted: close to 401. Composite 11.4–12.2; censored 62–72 %. Battery:
  pass.
- Confidence: medium.

### 506-bullington-blocked-paths (control)
- Change: `cfg.diffraction = "bullington";` and
  `cfg.diffraction_region = "blocked_paths";`
- Source: B04 reviewer pass (missing control); P.526-16 section 4.5.1.
- Rationale: reach ITM's blocked line-of-sight-region paths with Bullington
  but without the delta construction.
- Predicted: like 201 (56 %): censored 45–60 %, R2 measured mean error −6
  to −10 dB. Battery: fail as listed (by 0.3 dB over the margin).
- Confidence: medium.

## Alternatives and order
