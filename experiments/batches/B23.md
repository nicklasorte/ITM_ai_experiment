### 3.3 Censoring and uncertainty

Keep the existing frozen flags and loss values for exact D20c reproduction. For strict analysis, derive observed-run intervals from the documented raw censor coding after confirming marker semantics: detected [a,a], valid censored [a,+inf] in excess-loss dB, missing/invalid runs excluded as in builder. The frozen builder removes 500 from flagged values before taking medians. Median is coordinatewise monotone, so an interval for the aggregated run median is [median(lower runs), median(upper runs)] with the same even-count convention as MATLAB; add the row's frozen FSPL to both. For mixed censored runs this can give a finite upper bound, even an exact median. If source semantics cannot be verified, use the frozen conservative [meas_lb_db,+inf] for flagged rows as a labeled sensitivity only; do not fabricate an exact median. Do not change flags used by the evaluator. An exact interval from censoring arithmetic is not zero measurement uncertainty.

For any contrast X−Y the feasible interval is [X_lo−Y_hi, X_hi−Y_lo]. Use extended-real endpoints; never evaluate inf−inf as a number. Both one-sided unbounded rows generally yield [-inf,+inf]. Finite upper bounds recovered from the raw run medians can make some formerly flagged contrasts informative. Report the two approaches separately. For point prediction p and interval [l,u], violation depth = max(l−p,p−u,0) over finite endpoints; uninformative intervals are counted but not in the violation denominator. Exact contrast error uses detected pairs for primary comparability; raw-identified exact medians from flagged rows are secondary. Do not interpret interval distance as exact prediction error or use it as a likelihood.

No known numerical instrument uncertainty is assumed. Document available calibration and run variability; use raw within-row spread as a repeatability proxy only, not total measurement uncertainty. Report sensitivity to plausible documented common-mode and differential calibration errors if available; otherwise label calibration uncertainty unquantified.

### 3.4 Common statistics and decision language

Primary contrasts use one predetermined pair per configuration, then equal physical-base weighting (average repeated configuration contrasts within each base; do not pool thousands of frequencies as independent trials). Display per-site summaries, group counts and fixed-terminal clusters. Use paired, 2,000-resample bootstrap, seed 20261124, whole physical-base clusters within site for conditional descriptive intervals, retaining all rows of sampled bases; also leave-one-fixed-terminal-out where identifiable and leave-one-site-out sensitivity. Do not claim the path bootstrap represents independent fixed-terminal or cross-site sampling; R1–R3 can each have a single fixed receiver. With fewer than 10 independent bases in a site/cohort or fewer than two sites with eligible evidence, report descriptive results only. Ten is a planner-chosen minimum reporting threshold, not a power calculation. No claim of external validation from three or four reused sites.

Set provisional planning resolution: 1 dB in the primary dB contrast, chosen to avoid pursuing negligible changes. This is a research prioritization threshold, not an acceptance gate or a claimed instrument accuracy. Report effect and 95% conditional interval; require interval half-width ≤1 dB and documented differential calibration uncertainty small enough to distinguish the effect for a directional conclusion. If the uncertainty is unknown, call evidence provisional. Report both sign and magnitude; do not use a nonsignificant result as equivalence. Secondary strata are exploratory and not a new multiplicity policy. No p-value mining, post-outcome regrouping, or model selection on reported comparisons.

### 3.5 Geometry classification

Use the row's actual structural antenna heights and frozen profile; compute physical clearance separately from ITM mode and from 707's modified C-row geometry. Obtain effective curvature using the exact ITM initialization formula and input height/reference convention, verify against a direct core diagnostic or source. Do not assume 4/3 Earth. For interior distance x and path length d, direct-ray clearance is endpoint chord height minus terrain elevation minus x(d−x)/(2a_e). Normalize by first Fresnel radius sqrt(lambda*x*(d−x)/d), SI units, lambda=c/f. Check endpoints excluded, flat/single-obstacle analytical controls and reciprocity. Use c from the pinned source or declare 299792458 m/s for this report-only diagnostic. Label blocked if any interior clearance ≤0; clear if all positive; report marginal/clearance sensitivity with the minimum normalized clearance, including a secondary ≥0.6 Fresnel-clearance stratum. The zero boundary is geometric, not proof of observed LOS. If effective-curvature reproduction cannot be verified, stop geometry-dependent conclusions. Record classification at both paired heights/frequencies and separate changing-class paths; no measured-outcome selection.

**Estimands:** T=(L_meas,high−L_pred,high)−(L_meas,low−L_pred,low), dB. Positive means additional high-frequency underprediction. Secondary T/log10(f_high/f_low), dB per decade. FSPL cancels in residual slope difference; verify using the row's frozen fs_db (which uses listed distance) without changing model profile-distance FSPL. For each model show T distribution and matched contrast absolute error |T|. Pair censor intervals using observed difference then subtract predicted difference; report informative bounds separately. Use primary exact pairs, equal-base summary and conditional bootstrap. No pooled across-path slope as physical attribution.

**Component analysis:** on each frequency log D20b actual/smooth cascade terms, smooth-reference increment, clipping and bound status; compute differences at fixed geometry. For C use D23b g/a1/i/m to separate height substitution from additive response. Record where bound activation changes; raw component differences before clipping are not causal final-loss contributions. Verify decomposition parity using stored final outputs; do not infer C·T causes overshoot (D20b's preregistered rule failed). If required component unavailable, report component analysis incomplete without inventing values; measured contrast diagnostic can proceed. Long-term data not needed; no score changes.

**Predictions:** O clear R2/VA T positive on matched high-band pairs; R3 weaker. Low-band obstructed pairs may have different residual signs; no universal frequency exponent. If matching removes the pattern, close frequency-scaling lead rather than fitting an offset. An observed pattern alone cannot identify unmodeled clutter or a diffraction mechanism.

**Decision D23c:** SUPPORT for replicated matched high-frequency underprediction if strict O clear T≥1 dB with lower conditional interval >0, required precision, and at least two eligible sites in the predicted direction, including R2 or VA, with no eligible site showing material opposite effect. CONTRADICT only if same rule in reverse; otherwise INCONCLUSIVE or LOCAL as appropriate. Report R2/VA independently, so absence at R3 is not assumed. If only limited cohort supports it, label exploratory. Any actionable model proposal requires separate source, exact-support/headroom and registration; no frequency multiplier permitted.

**What the numbers say, in plain terms.**
- Height: 707's loss falls less than the measured loss as the fixed antenna is raised on obstructed open paths, at all three Colorado sets. The size (+1.7 to +5.6 dB) varies by site, and the formal rule is not met only because no interval is narrow enough.
- Clutter: the model's C/O difference is mostly the additive term (+14.8 dB), with the height substitution shaving 2.3 dB on average and as much as 18 dB on one row, and a baseline mismatch of 2.0 dB because the twins are different terminals (935 of 1,400 pairs have different mobile coordinates and distances). The interaction is zero, so the two effects add exactly.
- Frequency: on open, clear-at-both paths, the measured loss rises about 4 dB more than 707's from the lowest to the highest eligible frequency, at R1 (+3.9 dB) and VA (+4.6 dB); R3 is near zero. Between the two frequencies of each open pair, 707's reference attenuation rises by 3.7 dB (R1), 7.8 (R2), 1.3 (R3) and 0.9 (VA) on average, and its troposcatter bound never changes status. These component differences describe the model; they don't identify a missing mechanism.
