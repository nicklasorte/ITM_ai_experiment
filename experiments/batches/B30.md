## 1. Question

On open-sited Phase 2 rows (siting O, where 707 adds no terminal clutter),
do 707's errors track how far the vegetation near each terminal rises above
its antenna, by site?

Physics, planner's inference: vegetation taller than an antenna near that
terminal adds loss that 707 doesn't model on O rows, so 707 should
under-predict loss (signed error negative) as the excess grows.

## 2. Data

- **Vegetation:** LANDFIRE 2016 Remap Existing Vegetation Height (EVH),
  CONUS, 30 m, from the USGS image service
  `lfps.usgs.gov/arcgis/rest/services/Landfire_LF2016/LF2016_EVH_CONUS/ImageServer`
  (the earliest edition the service offers). Codes, from the LF2016 Remap
  EVH data dictionary: 101 to 199 are tree height = code − 100 m (199 is
  99 m or more); 201 to 230 are shrub height = (code − 200)/10 m; 301 to 310
  are herb height = (code − 300)/10 m; every other code (water, developed,
  crops, sparse, no data) is treated as 0 m vegetation height, and counted.
- **Sampling:** every sample of every Phase 2 profile, on the great circle
  from transmitter to receiver at the profile's own spacing (B17's
  pattern), nearest pixel. Builder:
  `experiments/batches/d30_build_evh_rev1.m`. Output:
  `experiments/D30-landfire-evh/phase2_profiles_evh_rev1.csv`, run-length
  encoded like the NLCD file, with a SHA-256.
- **Errors:** `var_lb_50 − meas_lb_db` from
  `707r-rescore-screen36/predictions_phase2.csv`, uncensored rows only.

## 3. Registered rule

Per path, H_tx and H_rx are the mean vegetation height (m) over the profile
samples within 300 m of the transmitter and of the receiver (non-vegetation
samples count as 0 m). Per row, the excess is
E = max(0, H_tx − h_tx) + max(0, H_rx − h_rx), with h the antenna heights
from `data/links/phase2_links_rev1.csv`.

Deciding population: uncensored siting-O Phase 2 rows, by site (R1, R2, R3,
VA).

For each site: ordinary least squares slope of the signed error on E, with
a 95 % percentile interval from a bootstrap that resamples paths (2,000
draws, seed 1). Sites with fewer than 10 paths that have E > 0 are reported
as descriptive and don't count.

Outcomes:

- **A (signal):** at least two counted sites have a negative slope whose
  interval excludes zero, and subtracting each counted site's fitted line
  lowers the RMS of the signed error on the deciding population by at least
  0.5 dB (in sample, so optimistic; labeled). Next step: a planner writes a
  data PR proposal for the EVH file and a model candidate with a cited
  method.
- **B (no signal):** anything else. D1 closes; D2 (Ofcom) is next per the
  data proposal.

Both thresholds (two sites, 0.5 dB) are planner-chosen.

Exploratory, reported but not deciding: the same slope on siting-C rows
(where 707 already adds P.2108-1 clutter), and the slope on the
along-path vegetation fraction (share of samples with tree height ≥ 5 m).

Decision on the deciding population (12,570 rows on 400 paths): one counted
site (R2) has a negative slope whose interval excludes zero; the rule needs
two. Subtracting the per-site lines lowers the RMS from 11.32 to 11.05 dB
(0.26 dB, in sample, so optimistic); the rule needs 0.5 dB. **Outcome B.**

Reading of the RMS rule: the script subtracts only the slope part of each
counted site's line, err − b(E − mean E), and keeps the site's mean error.
Subtracting the full line, intercept included, gives 11.32 to 10.90 dB
(0.42 dB, fresh reviewer's recomputation). Outcome B holds under either
reading.
