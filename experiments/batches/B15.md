# Batch B15: per-percentage combination of diffraction and troposcatter, with ITU-R P.617-6 fading

Planner: Claude Fable 5.2, 2026-11-23. Parent: `best` (707). Requested by
Nick on 2026-11-23. No code, no runs.

**Status: designed, and ruled out by a ceiling before any build.** The
design below is the one to build if this family is ever built. It isn't
recommended as a keep attempt: a change that fixed every fading-side shape
bias perfectly would gain 0.10 dB, against the 0.3 dB gate. Nick decides
whether to record it as screened out or run it once as a diagnostic.

## Results of the planning analysis

- **Ceiling.** If a model removed the mean shape error (L_p − L_50) in every
  band × distance cell at 90 % and 99 %, the composite would gain 0.07 to
  0.10 dB (screened 0.11 to 0.12). On both sides of the median the ceiling
  is 0.14 to 0.21 dB (screened 0.36 to 0.48). No time-variability model that
  varies smoothly with band and distance can pass a 0.3 dB gate on the full
  composite. Reproduce: `python3 experiments/batches/hm_ceiling_rev1.py variability`.
- **Proxy from stored runs.** 707 with D06a's fading side (90 % and above)
  scores +0.12 dB on the composite and +0.01 dB on the screened composite.
  Reproduce: `hm_ceiling_rev1.py hybrid --other experiments/D06a-p617-time-mode3 --take 90 99 99.9 99.99`.
- **Why the fading side isn't the clean win D06 suggested.** The gain at
  100-300 km is real (shape RMS at 99 %: 6.2 to 4.4 dB at 0.3-1 GHz, 8.4 to
  6.7 below 0.3 GHz). Beyond 300 km above 1 GHz, P.617-6's spread is too
  narrow (2.6 to 8.1 dB at 3-10 GHz, 6.1 to 7.6 at 1-3 GHz), and the
  cell-balanced score gives those small cells the same weight.
- **Correction to B14.md and the D06 summary.** They said ITM predicts too
  little fading at 99 %. It's the reverse. The shape error at 99 % is positive
  beyond 100 km (+1.1 to +4.0 dB by cell), so ITM predicts too much fading
  there, and P.617-6's narrower spread is what helped. B14.md is corrected.

## Design

### Sources

- ITU-R P.617-6 (09/2025) §4.1, eqs. (1)-(7b): troposcatter time deviate Y_p
  (`itm_variant/p617_troposcatter_rev1.m`, read from the rendered PDF in
  B14). §4 states the method is for non-exceedance percentages above 50 %.
- ITU-R P.452-18 eq. (64), the overall prediction:
  L_b = −5 log₁₀(10^(−0.2 L_bs) + 10^(−0.2 L_bam)), which combines troposcatter
  with the other modes (section number TODO; equation form confirmed against
  Nick's `matlab_itu_p452` port, which matches the ITU-R reference
  implementation).
- 707's bound (B06): beyond the horizon the troposcatter field is present
  whatever the terrain does to the diffracted field, so the scatter loss
  bounds the diffraction loss.

### Quantities, for one transhorizon path

All are attenuations relative to free space, in dB, before ITM's soft limit.

- A_d: 707's delta diffraction attenuation (`delta_bullington_reference`),
  before the bound.
- A_s: ITM's troposcatter line at the path distance,
  A_5 + M_s (d − d_5), floored at 0, as 707's `itm_troposcatter_line` bound
  uses it. Defined where ITM computes a scatter loss (A_5 < 1000).
- Y_I(z): ITM's time deviate (positive below 50 % time).
- Y_P(z): P.617-6 eq. (6) deviate at p = 100 Q(z), with h_0 from eq. (7) for
  the path. Used only for z < 0 (above 50 % time).
- C: ITM's remaining terms (V_med, location and situation deviates), the
  same for both components.

707 today: A(z) = min(A_d, A_s) − Y_I(z) − C at every percentage.

### 1501, `cfg.time_variability = "p617_fade_bound"`

Apply 707's bound at each time percentage instead of at the median only:

- p ≥ 50 % (z < 0): A(z) = min(A_d − Y_I(z), A_s − Y_P(z)) − C
- p < 50 % (z ≥ 0): A(z) = min(A_d, A_s) − Y_I(z) − C (707, unchanged)

Then ITM's soft limit, once. Properties:

- **Median unchanged.** At 50 % both deviates are 0, so A = min(A_d, A_s),
  which is 707 exactly. Every 50 % value, every Phase 2 number and the level
  score at 50 % are untouched.
- **Enhancement side on ITM.** Below 50 % the model is 707.
- **No region switch.** Both components are computed on every transhorizon
  path. ITM's crossover distance d_x and its mode flag aren't used. Where
  diffraction dominates, the result is 707; where scatter dominates, the
  scatter component fades by P.617-6.
- **Continuous in time percentage.** The two branches meet at 50 %.
- **One model.** Apply it on every profile path, long-term or Phase 2
  (PR #7 has dN for all 840 paths). Phase 2 is scored at 50 % only, so
  nothing scored there changes. Drop B14's long-term-only gate for this
  switch.

### 1502, `cfg.time_variability = "p617_fade_blend"`

As 1501, with P.452-18 eq. (64) in place of the minimum:

- B(x, y) = −5 log₁₀(10^(−0.2 x) + 10^(−0.2 y))
- p ≥ 50 %: A(z) = B(A_d − Y_I(z), A_s − Y_P(z)) − C
- p < 50 %: A(z) = B(A_d, A_s) − Y_I(z) − C

B is at most 1.5 dB below the minimum (5 log₁₀ 2, where the two are equal)
and tends to it when they differ by more than about 10 dB. The median
changes by 0 to −1.5 dB on transhorizon paths where the scatter line is
within 10 dB of the diffraction loss, on Phase 2 rows too. P.452-18 defines
eq. (64) for p ≤ 50 % with its own terms; using its form here is a design
choice. The combination must be made before ITM's soft limit, or the two
branches don't meet at 50 % when the loss is below free space.

### Implementation notes for the worker

- Split `variability` so it can return the pre-limit value for a given
  A_ref and deviate; combine; apply the limit once.
- Reuse `p617_context` for h_t, h_r and dN. h_s isn't needed (eq. (5) isn't
  used). Pass G_t + G_r = 0.
- If P.617-6's scatter angle θ ≤ 0 on a path ITM calls transhorizon, use
  Y_I for the scatter component (707) and count the rows in the smoke test.
- Keep B14's rule that deviates with |z| ≤ 4.5e-4 are exactly 50 %.

## Where a step could appear

| # | Where | Cause | In 707 already? | Size |
| --- | --- | --- | --- | --- |
| 1 | Radio horizon (ITM mode 1 to 2) | The bound and the scatter component start to apply | Yes, at the median, when A_s < A_d at the horizon | 1501 adds at most \|Y_P\| − \|Y_I\| at that percentage, only on paths where A_s < A_d + (\|Y_I\| − \|Y_P\|) at the horizon. 1502 adds up to 1.5 dB at the median. |
| 2 | A_5 reaches ITM's 1001 sentinel | ITM stops computing a scatter loss, so the component switches off | Yes | Same as 707 at the median; tails as row 1 |
| 3 | Scatter angle θ crosses 0 | Fallback from Y_P to Y_I | No | Up to \|Y_P\| − \|Y_I\|; expected only at the horizon |
| 4 | Horizon obstacle changes with distance or antenna height | θ_t, θ_r jump, so h_0 and Y_P jump through exp(−h_0/h_b) | ITM's own terms jump there too | Bounded by the change in Y_P; measure it |
| 5 | Crossing of the two components | min has a kink | Yes, at the median | No step (continuous); 1502 is smooth |
| 6 | 50 % time | Deviate snap at \|z\| ≤ 4.5e-4 | No | Under 0.05 dB |
| 7 | 50 % time, loss below free space (1502 only) | Soft limit applied before combining | No | Zero if combined before the limit |
| 8 | Frequency | Y_P has no frequency term; ITM's d_e and scatter line do | Yes | No new step expected |
| 9 | ITM's crossover d_x | Not used by this design | The 707 bound doesn't use it either | None |

## Checks before any run

1. **Tests** (`itm_variant/tests/test_diffraction_rev1.m`), new
   `test_p617_fade_bound`:
   - Every 50 % value equals 707's to 1e-6 dB on synthetic paths.
   - For p < 50 %, 1501 equals 707 exactly.
   - Where A_s − A_d > 40 dB, 1501 equals 707 at every percentage.
   - Where A_d − A_s > 40 dB, the 99 % value equals A_s − Y_P − C by hand.
   - For 1502, B(x, x) = x − 1.505 and B(x, x + 30) = x to 1e-5.
   - Loss is non-decreasing in p from 50 % to 99.99 %.
2. **Parity.** Defaults match the stored baseline to 1e-9 dB on all rows.
   With 707's settings and the new switch off, the stored 707 run to 1e-9 dB
   (built into `b13_smoke_rev1.m`).
3. **Smoke test** (`itm-smoke-test` skill), per-row deltas against 707.
   Report the count of rows where each component wins at 99 %, the range of
   h_0, and the count of θ ≤ 0 fallbacks. For 1501, any nonzero change at or
   below 50 % is a bug: stop.
4. **History-matching screen** on the deltas, with the floor. Append the
   interval, the central estimate and the required ρ to this file.
5. **Continuity at 1, 50 and 99 % in distance.** A new planner script
   `b15_continuity_rev1.m` on the battery's smooth and rough synthetic
   profiles, 2 km steps from 10 to 400 km, at 150, 900 and 3,000 MHz:
   - Pointwise rule: at every step, |ΔL_variant| ≤ |ΔL_707| + 1 dB at each
     percentage. Comparing only the largest steps (as the battery does) hides
     a new step wherever stock already has a bigger one elsewhere.
   - Also sweep receiver height from 1 to 30 m on the ridge profile at 99 %.
   - A failure makes the run a diagnostic; it can't be kept.
6. **Physics battery** (`b14_battery_rev1.m` pattern).
