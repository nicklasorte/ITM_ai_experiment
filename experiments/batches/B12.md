## Purpose

- **H02.** ITM's line-of-sight two-ray term uses a flat-Earth path
  difference. On long line-of-sight paths the specular point and the
  reflected path length depend on Earth curvature. Test whether the
  curved-Earth phase from ITU-R P.530-19 improves line-of-sight rows.
  Not tested here: the package's P.530 eq. (132) divergence-amplitude rival
  (H18).
- **H03.** D05 found the long-term spread too narrow below 100 km and too
  wide beyond 300 km. Test whether treating a path with one common horizon
  crest as two links in tandem, each with its own ITM time variability,
  changes the spread in the right direction.

## Code

- `itm_variant/los_phase_curved_rev1.m` (H02). Specular-point geometry from
  ITU-R P.530-19 Annex 1 section 6.1.2.3, eqs. (121)-(126): normalized height difference c, curvature
  parameter m, the cubic root b, the reflection-point distance d1, and the
  heights u and v of each antenna above the plane tangent at the reflection
  point. Phase difference 2kuv/s, set to 0 when u or v is not positive.
  Switch: `cfg.los_phase = "itm" | "curved_specular"` (default `"itm"`).
- `itm_variant/two_leg_quantiles_rev1.m` and `two_leg_geometry` in
  `itm_p2p_core_exp.m` (H03). When both terminals see the same horizon
  sample and it blocks the line of sight, each leg gets an effective
  distance from its own length and effective heights, and the time
  deviation is the quantile of the sum of the two legs' deviations,
  convolved on a 1,201-point normal grid, centred at the median. The
  two-leg result is blended with ITM's by a weight
  w = u+^2 / (1 + u+^2), from the crest's Fresnel clearance over each leg.
  Switch: `cfg.time_variability = "itm" | "two_leg"` (default `"itm"`).
- Source for H03: NBS Technical Note 101, vol. I, sections 10.3-10.4 and
  10.8, which treat the common ridge as a shared terminal and convolve the
  two leg distributions under independence; ITM's own variability function
  is used for each leg. TODO: reproduce the
  TN101 section 7.5 worked example (184.8, 191.3, 195.5 dB) before
  claiming the convolution matches TN101; not done in this batch.

### Deviation from the package (H02)

The package text sets the two antenna heights above the reflection plane
equal to each other. That holds only for equal antenna heights. The code
uses the P.530-19 specular geometry, which gives separate u and v. Recorded
here before any score.

## Experiments

### 1201-curved-specular-phase
- Change (launcher overrides): 707's five settings plus
  `"los_phase":"curved_specular"`.
- Source: ITU-R P.530-19 Annex 1 section 6.1.2.3, eqs. (121)-(126),
  specular-point geometry on a spherical Earth.
- Predicted: R1 mean rises 0.1-0.3 dB and R1 RMS changes by less than
  0.3 dB; VA mean moves from -2.9 toward -2.6 dB and VA RMS changes by less
  than 0.3 dB; R2 and R3 change by less than 0.1 dB. Composite within
  0.2 dB of 707 (12.3-12.7); screened gain against 707 under 0.3 dB, so
  the gain gate fails. Censored violations fall by at most 0.5 points
  (loss only rises). Long-term level changes by less than 0.1 dB. Most
  likely: rejected for too small a gain, not for harm.
- Confidence: medium-high.

### 1202-two-leg-time-variability
- Change (launcher overrides): 707's five settings plus
  `"time_variability":"two_leg"`.
- Source: NBS Technical Note 101, vol. I, sections 10.3-10.4 and 10.8
  (common-ridge paths), with ITM's time variability per leg; precedent in
  Barsis and Kirby (1961).
- Predicted: Phase 2 scores identical to 707. Long-term shape RMS changes by
  less than 0.05 dB; composite within 0.05 dB of 707; the gain gate fails.
  Most likely: rejected. This run doesn't test H03's claim about the
  troposcatter regime, because the common-crest gate excludes those links;
  a fair test needs a different leg definition, which would be a new
  hypothesis.
- Confidence: high.
