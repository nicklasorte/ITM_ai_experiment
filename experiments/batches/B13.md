# Batch B13: ITU-R P.452-18 troposcatter loss in ITM's scatter line

Planner: Claude Opus 5.5, 2026-11-23. Parent: `best` (707). Score with
`Best="707-cascaded-isolated-clutter-at-r"`. Requested by Nick on
2026-11-23 ("Run all of those").

## Purpose

The headroom map (`experiments/proposals/headroom_map_rev1.md`) puts the
largest remaining error in the long-term troposcatter class. Long-term
level is 19.1 of 707's 12.5 dB composite parts, and that class could gain
about 3 dB at a 5 dB floor. ITM's troposcatter attenuation (the H_0 and
F(θd) functions of ITM v1.4) dates from NBS TN 101. ITU-R P.452-18 eq. (45)
is a later fit to troposcatter measurements. Test whether it does better
inside ITM's own line structure.

## Code

- `itm_variant/p452_troposcatter_rev1.m`: ITU-R P.452-18 section 4.3,
  eq. (45), (45a), (45b), with A_g from eq. (9).
- `itm_variant/gaseous_p676_rev1.m`: ITU-R P.676-11 Annex 1 line summation,
  eqs. (1)-(9), Tables 1 and 2, as P.452-18 eq. (9) requires (water vapour
  3 g/m³ on the troposcatter path; 15 °C and 1013.25 hPa).
- `itm_p2p_core_exp.m`, `troposcatter_loss`: switch
  `cfg.troposcatter = "itm" | "p452_45"` (default `"itm"`). With
  `"p452_45"`, the scatter attenuation is L_bs(50 %) minus free-space loss:
  - only where ITM itself computes a scatter loss (ITM returns 1001
    elsewhere, and that's kept)
  - only at 100 MHz and above, the lower end of P.452-18's scope; ITM's
    value below
  - path angular distance θ = θ_t + θ_r + d/a_e (P.452-18 Table 4
    definition), with ITM's horizon angles and effective radius
  - N_0 = the sea-level refractivity input; G_t + G_r = 0 dBi, because the
    records carry no antenna gains (TODO in the code)
- ITM's scatter line through (d_5, A_5) and (d_6, A_6) is built from these
  values, so 707's `itm_troposcatter_line` bound and ITM's crossover
  distance d_x use them too. Time variability is ITM's, unchanged.

### Deviations from P.452-18, recorded before any score

- P.452-18 uses its own effective radius from the ΔN map (eqs. 5-6). ITM's
  effective radius from N_s is used instead, because the ΔN map isn't a
  frozen input and the ITU forbids redistributing its digital maps.
- P.452-18 combines troposcatter with the other modes by power sum
  (eq. 64). ITM's line structure and region switch are kept instead.
- P.452-18 doesn't apply above 50 % time. Only the 50 % value enters, as
  ITM's reference attenuation; ITM's variability supplies the rest.

## Result and planner analysis (2026-11-23)

- **1301 rejected.** Composite 12.8 dB (gain −0.30, 95 % −0.48 to −0.02);
  screened gain +0.04 (−0.08 to +0.15). R1 improved (10.5 to 10.2), the
  other sites didn't move, censored violations 23.5 %. Every registered
  prediction held except the composite, which missed by 0.1 dB.
- **The screen worked as designed.** The actual gain is inside its interval,
  close to the central estimate (−0.23), and the effective correlation with
  707's error was −0.10, far from the 0.64 a keep needed.
- **The harm sits in the 36 screened-out links,** where 707 is already
  25 dB pessimistic and P.452 adds 2.4 dB. On the other 512 links the change
  is nearly neutral.
- **Implication.** A different troposcatter median isn't the lever; the
  class's error is spread, not level. Next candidates:
  1. ITU-R P.617-6 eqs. (4)-(7): its time distribution on both sides of
     50 %, which bears on spread. Needs dN at each path centre, a `data/`
     PR (derived per-path values; the ITU map itself can't be published).
  2. Path vegetation along the profile (headroom map M11), also a `data/`
     PR.
