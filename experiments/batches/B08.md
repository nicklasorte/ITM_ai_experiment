# Batch B08: ITU-R P.2108-1 terminal clutter applied as the Recommendation says

Planner: Claude Opus 5.5, 2026-11-21. Parent: 000-baseline (best). Follows
the B07 reviewer pass (`experiments/B07-reviewer-pass/`, 3 of 3 HOLD on
701 and 704).

## Purpose

The B07 reviewers found that 701 adds the ITU-R P.2108-1 section 3.1 term
to the wrong base. The Recommendation adds A_h to "basic transmission loss
... calculated to/from the height of the representative clutter height
used" (section 3.1; Table 1 says the same), with A_h = 0 when h >= R. 701
ran ITM at the real mobile height (2 to 14.5 m) and then added A_h, so the
gain from h up to R = 15 m was counted twice. B08 runs the term as written
and answers the reviewers' "required before keep" list:

1. Path loss computed with the concealed mobile antenna at max(h, R), then
   A_h at the actual height. No new free parameter.
2. Above 3 GHz, A_h held at its 3 GHz value (`"hold3"`), with the
   `"extend"` run reported beside it.
3. Censored violations reported by site.
4. A MATLAB test of all 18 valid NTIA/ITS test vectors.

## Code (itm_variant/ only)

- `cfg.terminal_clutter_base`: `"actual"` (B07; default, so 701 to 706
  reproduce) or `"clutter_height"` (B08). The mobile end and its actual
  height are fixed in `clutter_terminal` before any height is used, and the
  whole path (horizons, effective heights, the delta reference, the bound)
  is computed with that antenna at max(h, R).
- `p2108_height_gain_rev1` returns R as a second output, takes the
  frequency rule `"hold3"`, and takes optional `R_m` and `w_s_m` overrides
  used only by the test-vector test.
- Tests: 33 of 33 pass. New: all 18 valid NTIA/ITS vectors to 0.05 dB and
  the 5 error rows; `"hold3"`; the base-height switch (concealed row =
  ITM at max(h, R) + A_h; reversed call equal; open rows and h >= R
  unchanged; unknown base fails loud).
- Parity at the defaults: 6.8e-13 dB (run tag `scratch-parity-b08`,
  git-ignored). Default `params_exp.m` MD5 changes to
  e445ee80afe8fc350b047dfcf7d21bdb (one new line,
  `cfg.terminal_clutter_base = "actual";`).
- Battery (merged `eval/`, with the height-gain check), B08 settings:
  `delta_cascaded_isolated` pass (height-gain net +0.17 dB; reciprocity
  p95 6.8e-8 dB); `delta_deygout_isolated` pass (+0.19 dB; 7.1e-8 dB).
- New helper: `experiments/batches/b08_censored_by_site_rev1.py <tag>...`
  (by site and siting; reproduces the logged totals for 604, 701, 702).

three B07 reviewers to check their required-before-keep items; a keep needs
